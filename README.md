# Military Spouse Support App 🇺🇸

A simple web app to help military spouses stay organized and connected.  
Includes a PCS checklist, curated resources, and personal notes that automatically save in your browser — no login or backend required.

## 🌟 Features
- 🏠 Home page with quick notes (autosaves locally)
- ✅ PCS / life checklist with “Share list” button (creates a shareable link)
- 🌐 Resources page with official links
- 💬 About page explaining how the app works
- 💾 Works completely offline — all data stored in your browser
- ⚡ Built with [Next.js](https://nextjs.org) and easily deployable on [Vercel](https://vercel.com)

## 🚀 How to Use
1. Deploy it on [Vercel](https://vercel.com) (no setup needed).
2. Share the link with your partner or family.
3. Use the checklist and notes — everything saves locally!

## 🛠️ Tech Stack
- Framework: **Next.js (App Router)**
- Language: **TypeScript + React**
- Hosting: **Vercel**
- Storage: **localStorage (no database required)**
